行情與資料來源

即時模式：讀取 Binance Spot 公開市場資料，不需要連接錢包或提供 API 金鑰。即時價格約每 60 秒更新一次；近期高低點由 1 小時 K 線計算，啟動時載入最近 168 根（約 7 日）。

資料來源：Binance Spot API 官方文件；公開資料 API 位於 data-api.binance.vision。本程式讀取 /api/v3/ticker/24hr 與 /api/v3/klines。交易對為 BTC/USDT、ETH/USDT、SOL/USDT、BNB/USDT、DOGE/USDT。

解讀方式：行情來自單一交易所，不代表所有平台的綜合價格。遊戲以 USDT 報價近似美元顯示，未換算 USDT/USD 匯率。高點或低點只描述近期區間位置，不代表趨勢或買賣建議。

虛擬帳戶：交易所行情與隨機模擬行情各自保存餘額、寵物、交易紀錄和價格歷史。切換模式會進入另一份帳戶，不會拿新行情重估上一模式的寵物；首次使用的模式會建立獨立虛擬資金。

NFT 資料範圍：寵物先在本機養成，成熟後才鑄造。V2 NFT 記錄幣種、成熟階段、稀有度和鑄造時間；虛擬持倉、買賣與養成歷程留在本機，合約不會驗證這些歷程。

舊存檔：有記錄行情模式的存檔會留在上次使用的帳戶；較舊且沒有模式欄位的存檔會遷移到隨機模擬帳戶，即時行情帳戶會另行建立。

遊戲操作：買入與賣出仍是本機模擬交易，不會送出真實訂單。模擬模式會以隨機行情運作，資料來源狀態會明確標示。
